## Featured Projects

### [AI Food Recommendation Chatbot — Multi-Agent RAG System](https://github.com/aguru-venkata-saisantosh-patnaik/AI_Food_Recommendation_Chatbot-Multi_Agent_RAG_System)

A production-style RAG architecture where three specialised agents collaborate — a conversational agent handles dialogue, a sharded ChromaDB retrieval agent fetches semantically relevant dishes, and a GPT-4o-mini reranker filters and ranks results. User preferences are modelled using K++ clustering so recommendations adapt to taste profiles over time. Built with LangChain and served via Gradio.

*LangChain · ChromaDB · GPT-4o-mini · K++ Clustering · Gradio*

### [Chandrayaan-2 Lunar XRF Mapping](https://github.com/aguru-venkata-saisantosh-patnaik/chandrayaan2-lunar-xrf-mapping)

Full pipeline for extracting elemental composition of the lunar surface from raw CLASS (XRF spectrometer) FITS files — solar flare gating, adaptive moving-average background correction, multi-Gaussian spectral decomposition for 9 elements, and uncertainty propagation through spectral overlap. The output is a GPU-rendered interactive map (WebGL via Plotly Scattergl) where every 12.5 × 12.5 km observation cell is a hoverable pin showing element/Si ratios with uncertainties. Sub-pixel resolution achieved by KD-tree regridding and averaging overlapping orbital passes. Built for Inter IIT Tech Meet 13.0 (ISRO PS4).

*astropy · NumPy · SciPy · Plotly Scattergl · WebGL · OpenCV*

### [App Feedback Analysis](https://github.com/aguru-venkata-saisantosh-patnaik/App_Feedback_Analysis)

NLP pipeline that scrapes 100k+ Meesho Google Play Store reviews, runs LDA topic modelling to surface latent complaint and feature clusters, and applies sentiment analysis to quantify directional user sentiment per topic. Gemini API is used to synthesise insights and generate actionable product recommendations. Results were applied to a live Meesho AOV/NMV growth case study.

*Gemini API · LDA · Sentiment Analysis · google-play-scraper · Python*
